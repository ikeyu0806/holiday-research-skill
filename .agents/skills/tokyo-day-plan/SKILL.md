# 東京の休日を計画する

**手順は `docs/skills/tokyo-day-plan.md` に準拠する。** このファイルには手順を書かない（Claude Code / Cursor と共有しているため）。

1. `docs/skills/tokyo-day-plan.md` を全文読む
2. 出典URLは `docs/skills/references/tokyo-sources.md` を開き、そこに書いてあるページで開催情報を確認する
3. 展覧会、上映、イベント、料金、休館日は、開いたページの文言だけを書く
4. チケットの購入と予約操作はしない
