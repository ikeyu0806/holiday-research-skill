# プライベートの予定を調べる

**このファイルが正本。** 仕事終わりの夜、休日、数週間から数ヶ月先のプライベートを、都内の催し、スポーツ、サウナ、家で見る番組から調べて提案する。

開催中の名前、会期、料金、休館、上映時刻、放送日時、発売日は、このファイルに書かない。調べるたびにページを開く。出典URLは [references/tokyo-sources.md](references/tokyo-sources.md)。

## いつ使うか

- 今夜、仕事終わり、この後に何をするか
- 今日、明日、今週末、指定日の休日やデート
- 来月以降、先に予約しておきたいこと、人気で枠が埋まりそうなこと
- 都内のイベント、祭り、マルシェ
- 美術館・展覧会、新しい施設
- 公開中・公開予定の映画
- 舞台、ミュージカル、歌舞伎
- お笑い、落語
- テレビ番組、見逃し配信
- ライブ、フェス
- スポーツ観戦、自分で出る大会、運動しに行く施設
- サウナ、温浴

カテゴリを一つだけ聞かれたら、そのカテゴリだけ調べる。夜の提案は「今夜」「仕事終わり」のとき、1日の提案は休日や指定日のとき、先のリストは先の予定を聞かれたときに出す。

## 種類

依頼から一つ選ぶ。複合していたら、ユーザーが主に聞いている方を種類にし、もう一方は短い節にする。

| 種類 | 依頼の目安 | 対象 |
| --- | --- | --- |
| 今夜 | 今夜、仕事終わり、業後、この後 | 今日の夜。出発の目安は 19:00。指定があればその時刻 |
| 休日 | 今日、明日、今週末、休日、デート、指定日 | その日の昼から夜 |
| 先の予定 | 来月、今年中、予約しておきたい、先行、フェスを押さえる | 指定が無ければ今日から3ヶ月 |
| 単カテゴリ | 舞台だけ、テレビだけ、など | 下の「単カテゴリの日付」 |

日付も種類も無い「何する」「プライベートの予定」は、今夜を本線にし、先に押さえるものを末尾に短く足す。種類は「今夜」と書き、仮定に「先の予定も短く添える」と書く。

## 既定

- 日付の未指定は、Asia/Tokyo の今日。範囲なら開始日と終了日を `YYYY-MM-DD（曜）` で書く
- 「明日」「今週末」「来月」も Asia/Tokyo
- エリア、人数、予算、興味が無いときは聞き返さず、次を仮定して先頭に書く。東京（フェスは首都圏）、大人1〜2人、予算は料金が公式に分かる範囲
- 今夜の興味の仮定は、夜に間に合う舞台・お笑い・映画・イベント・試合・サウナと、家で見るテレビを並べる
- 休日の興味の仮定は、アート・映画・その日のイベントを軸に、重なる舞台・お笑い・ライブ・試合を足し、サウナを候補に入れる
- 先の予定の興味の仮定は、発売・抽選・日時指定があるもの、開業、公演の開始を優先する
- 回答の言語は日本語
- チケットの購入、予約、会員登録はしない。予約ページのURLを渡す

## 手順

1. 種類と対象日（または範囲）を決める
2. 今夜と休日は [出典一覧](references/tokyo-sources.md) の天気を開く。先の予定は、対象日が週間予報に入るときだけ開く。入らなければ天気は「予報期間の外」と、開いたURLだけ書く
3. 下の「種類ごとに開くページ」だけ開く。頼まれていないカテゴリの索引は開かない
4. 索引が空、またはスクリプト向けの殻だけなら、ブラウザで描画後の一覧を読む。空の取得結果を「その日は何もない」と書かない
5. 今夜と休日は、対象日が会期・公演日・放送日・試合日・営業日に含まれるものだけ残す。終了済みと、まだ開いていないものは落とす。先の予定は、範囲に公演・開業・公開・発売・抽選・エントリー期間がかかるものを残す。未開業でも、開業日か予約開始がページにあれば残す
6. 足りないときだけ検索する。クエリは日付か範囲を入れる（例: `2026年10月 東京 舞台`、`2026年10月4日 東京 プロ野球`、`2026年10月 チケット 先行 東京`、`東京 サウナ 営業`）
7. 提案に入れる項目だけ、会場・劇場・放送局・施設・主催の公式を開く。日時、対象日の開館や営業、料金、予約や発売の要否を公式の文言で確認する。公式を開けない項目は提案に入れず、候補に「公式未確認」と残す
8. 提案を書き、完了条件を満たすまで出典の抜けを埋める

索引の件数は、開いたカテゴリごとに最大5。ユーザーが名前やジャンルを指定したらそれに合わせ、上限を超えてよいのは指定されたものを落とさないためだけ。

## 種類ごとに開くページ

### 今夜

天気、イベント、映画の公開中、舞台、お笑い、テレビ、LiveFans、サウナの東京都一覧を各1ページ以上。スポーツは NPB を1ページ。その夜の都内・首都圏の試合が無ければ、Jリーグの試合一覧を1ページ開いて打ち切る。アートは、索引に夜の開館が見えるときだけ。新しい施設と「先に押さえる」の公式一覧は開かない。調べたページに発売中・抽選中とあれば、その行だけ「先に押さえる」に書いてよい。

映画の上映時刻は、夜の回を確認する作品だけ。最大3作品。サウナは、出発目安以降も営業しているものだけ。

### 休日

天気、アート、映画、イベント、サウナの東京都一覧を各1ページ以上。その日に重なるか、舞台・お笑い・LiveFans を各1ページ。スポーツは NPB を1ページ。その日の都内・首都圏の試合が無ければ、Jリーグの試合一覧を1ページ。テレビは、夜を家で過ごす案を出すときだけ。新しい施設は「新しいところ」と言われたときだけ。相撲、Bリーグ、都立の体育施設、大会エントリーは、その競技や「運動したい」「大会に出たい」と言われたとき。

### 先の予定

アートの開催前が分かる一覧、舞台、お笑い、LiveFans、フェスの索引を各1ページ以上。スポーツは NPB の対象月と、相撲協会の本場所を各1ページ。映画は [公開予定](https://eiga.com/coming/) を、範囲に公開日が入りそうなときだけ。新しい施設の索引を1ページ以上。「先に押さえる」の公式を、興味の指定が無ければ次から最大3サイト開く。イープラスかチケットぴあ、三鷹の森ジブリ美術館、teamLab の東京。ディズニーはテーマパークやディズニーと言われたときだけ。Jリーグ、Bリーグ、東京マラソン、スポーツエントリーは、その競技や大会に出たい・見たいと言われたとき。サウナは、サウナを聞かれたとき。予約がページにあれば「先に押さえる」に書いてよい。

### 単カテゴリの日付

テレビ、舞台、お笑い、ライブ、映画、イベント、展覧会、スポーツ観戦、サウナで日付が無ければ今日。フェス、新しい施設、予約、公開予定、大会のエントリー、本場所の発売は今日から3ヶ月。

## カテゴリの見方

### アート

- 今夜と休日は、会期に対象日が含まれること。先の予定は、範囲に会期かチケット発売がかかること
- 休館は公式の休館欄を読む。月曜休館を一般論で決めない
- 終了まで7日以内なら「まもなく終了」と書く
- 料金は公式に書いてある金額だけ。割引も公式に明記があるものだけ

### 映画

- 今夜と休日は公開中から、対象日に都内で見られる作品を選ぶ。指定が無ければ、大規模公開と単館・特集上映を混ぜる
- 上映時刻は、対象日の劇場スケジュールを開いたものだけ。劇場名、時刻、そのページのURLをセットで書く。今夜は、出発目安より後の回だけ
- 座席の空きは書かない。予約URLを渡す

### イベント

- 対象日だけの催しを、通年施設より先に出す
- 通年の観光施設は、ユーザーがエリアを指定したときの補足に留める

### 舞台

- 公演日が対象に入るものだけ。開演、劇場、料金、チケットの状態は、開いたページの文言だけ
- 歌舞伎はかぶきびと、または松竹のページで月の公演を確認する

### お笑い

- FANY は都道府県を東京にして探す。落語は協会のページ、松竹芸能は松竹芸能のページ
- 「売切れ」「発売中」はページの表示だけ書く

### テレビ

- 番組名、局、放送日時は、番組表か番組ページに書いてあるものだけ
- 今夜は、出発目安以降の番組に限る。先の予定は、開始日が決まっている連続ドラマ・特番・スポーツ中継で、夜や休日を空けたくなるもの
- TVer にあるだけの作品は「配信」と書く
- 外出の案と、同じ時刻の視聴を一つの時系列に入れない。家で見る案として分ける

### ライブ・フェス

- ライブは LiveFans。フェスはフェス特集か Festival Life かイープラス
- 既定のライブは都内。フェスは首都圏を含め、都道府県を書く
- それより遠いフェスは、フェスやライブを聞かれたとき、またはページに先行・抽選・一般発売があるときに「遠方」として別枠にする。夜や1日の時系列には入れない

### スポーツ

- 観戦は、会場が東京か首都圏で、開始時刻がページにあるもの。都道府県を書く。それより遠い試合は「遠方」として別枠にし、夜や1日の時系列には入れない
- 今夜は、出発目安より後に始まる試合だけ
- 料金、チケット発売、売切れは、球団・クラブ・会場かリーグ公式の文言だけ。座席の空きは書かない
- 自分で出る大会は、エントリー期間がページにあるもの。先の予定では、締切がページにあるものを先に書く
- 体育館・プールなど運動しに行く施設は、営業時間と料金をその施設の公式で確認する

### サウナ

- 索引の一覧だけで提案に入れない。営業時間、料金、定休日、予約の要否は施設の公式で確認する
- 今夜は、出発目安以降も入れるものだけ。日付をまたぐ営業は、ページの営業時間をそのまま書く
- 性別の指定が無ければ、男女で営業や料金が違うときはその違いを書く。片方だけに絞らない
- 予約が要る店は、その案の先頭に書く。サウナはその案の最後のコマにする

### 先に押さえる

- 入れる理由は、ページにある発売期間、抽選、日時指定、開業日、公演開始、エントリー期間のいずれか
- 「人気」「売切れ近い」は、ページにその趣旨の文言があるときだけ書く
- 今夜と休日の「今日行ける」案に、未開業・未公開を入れない

### 新しい施設

- 開業・開館・グランドオープンの日付がページにあるもの、またはページが新しい施設として紹介しているもの
- 開業日が対象より前で、新しさの文言も無い記事は落とす
- 営業前でも、開業日か予約開始が確認できれば先の予定に入れる

## 提案の組み方

### 今夜・休日

- 基本は2案。興味が一つなら1案と、天気が崩れたときの予備。今夜の予備は、家でテレビか配信を見る案にしてよい
- 1案は同じエリアか、乗り換えて30分以内に収まる隣接エリア。区をまたぐ細かい分数は書かず、「移動は乗換案内で確認」とする。帰りも同様で、終電時刻は書かない
- 各案は時系列で2〜4コマ。開始の目安、滞在、次の場所。今夜は出発目安より前のコマを入れない
- 予約が要るものは、その案の先頭に書く。サウナは、その案の最後のコマにする
- 降水確率が高い日は、屋内の案か家で見る案を先に出す
- 食事の店は、頼まれたときだけ入れる。入れるなら公式か掲載ページを開いた店だけ

お台場と山手線の内側、吉祥寺・下北沢と上野、のように離れた地域を1本の時系列に詰め込まない。離すなら別案にする。

### 先の予定

行程にはしない。動く順に3〜7件。「いつまでに、何を、ページ上の発売・予約・開催、URL」。締切がページにあるものを先に並べる。

ユーザーが先の特定日を指定したら、その日に確認できたものだけで、休日と同じ時系列の案を1つ足してよい。

## 出力

```markdown
# プライベートの予定 — YYYY-MM-DD（曜）または範囲

確認: YYYY-MM-DD HH:MM（Asia/Tokyo）
種類: 今夜 / 休日 / 先の予定 / 単カテゴリ
仮定: （ユーザーが指定していない条件だけ1行）

## その日の天気
- 出典URLと、対象日の天気・降水確率・気温がページにあった範囲
- 先の予定で予報期間の外なら、その旨と開いたURL

## 候補
調べたカテゴリだけ見出しを出す。

### アート / 映画 / イベント / 舞台 / お笑い / テレビ / ライブ・フェス / スポーツ / サウナ / 新しい施設
表の列は、名称、場所または局、日時または会期、料金または放送、出典。映画は対象日に確認できた上映を入れる。

### 先に押さえる
| 名称 | いつ | ページ上の予約・発売 | 出典 |

## 提案
今夜・休日は案Aと案B。先の予定は動く順のリスト。

## 未確認
- 開けなかったページ、公式と索引の食い違い
```

候補がゼロのカテゴリは、表を空にせず「索引を開いたが、対象に重なるものを確認できなかった」と、開いたURLを書く。

単カテゴリの依頼では、頼まれていないカテゴリの表と、頼んでいない種類の提案は出さない。

## 完了条件

- 先頭に対象日または範囲、種類、確認した日時（Asia/Tokyo）がある
- 開催、料金、休館、営業時間、上映時刻、放送日時、試合の開始、発売、予約開始は、開いたページのURLが付いている
- 提案に入れた項目は公式ページを開いている。テレビは番組表か番組ページ、配信は TVer か放送局の配信ページ
- 確認できない数字を、それらしい値で埋めていない
- 未開業・未公開を、今夜や休日の「今日行ける」案に入れていない
- 購入・予約・会員登録の操作をしていない
