# プライベートの予定で開くページ

索引は候補を見つける入口。提案に入れる項目は、会場・劇場・放送局・主催の公式ページで日時、休館、料金、予約、発売を確認する。索引と公式が食い違うときは公式を採用し、食い違いを1行書く。

URL が 404 なら、サイト名で検索して現在の一覧を開く。切れたパスを繰り返さない。

## スポーツ

観戦の日程はリーグや協会の公式から開く。提案に入れる試合は、球団・クラブ・会場の公式で開始時刻、料金、チケット発売を確認する。

| 用途 | URL |
| --- | --- |
| プロ野球の試合（NPB） | https://npb.jp/ |
| Jリーグの試合 | https://www.jleague.jp/match/ |
| Bリーグの日程 | https://www.bleague.jp/schedule/ |
| 大相撲の取組（日本相撲協会） | https://www.sumo.or.jp/honbasho/ |
| 都立の体育施設（東京都スポーツ文化事業団） | https://www.tef.or.jp/ |
| 大会のエントリー（スポーツエントリー） | https://www.sportsentry.ne.jp/ |
| 東京マラソン | https://www.marathon.tokyo/ |

NPB の月間日程は、トップから対象月のページを開く。年や月がパスに入っていても、対象のページを使う。都立施設は、運動しに行くと言われたとき。大会とマラソンは、出たい・先に申し込みたいと言われたとき。
