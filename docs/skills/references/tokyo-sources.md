# 東京の休日プランで開くページ

索引は候補を見つける入口。プランに入れる項目は、会場・劇場・主催の公式ページで会期、休館、料金、予約を確認する。索引と公式が食い違うときは公式を採用し、食い違いを1行書く。

URL が 404 なら、サイト名で検索して現在の一覧を開く。切れたパスを繰り返さない。

## 天気

| 用途 | URL |
| --- | --- |
| 東京都の週間天気 | https://tenki.jp/forecast/3/16/ |
| 気象庁の東京地方予報 | https://www.jma.go.jp/bosai/forecast/#area_type=offices&area_code=130000 |

区を指定されたら、tenki.jp のその市区町村ページを開く。
